(a) Asset + Puls-Sequenz

✕

Erst wenn genug Reize zusammenkommen, feuert das Neuron — dann läuft ein Signal bis zur Synapse und springt auf die nächste Zelle über.

Wie ein Klingelknopf: Erst fester Druck löst das Klingeln aus.

// Contract-Auszug — das LLM sagt WAS, nie wo/wie
asset: { ref: biology.neuron, role: hero }
sequence:          trigger: auto
  - reveal    asset:neuron
  - pulse     node:dendrit → node:soma
  - pulse     node:soma → node:synapse
  - highlight label:synapse
